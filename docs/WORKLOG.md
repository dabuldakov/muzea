# Журнал доработок Muzea

Здесь фиксируем, **что и когда** менялось, в какой версии вышло и к какой
области каталога относится. Каталог и коды — в [FEATURE_CATALOG.md](FEATURE_CATALOG.md).

## Правила

- Каждая запись: дата, версия, тип (`feat/fix/perf/refactor/test/build/docs`),
  код области (`MSG.02`, `MEDIA.07`, …), короткий результат и коммит.
- Если у изменения нет подходящего кода — сначала добавляем пункт в каталог,
  потом пишем запись. Без кода запись не оставляем.
- В сообщении коммита код указываем в конце темы: `fix(chat): ... [MEDIA.07]`.
- Релизный коммит `release: X.Y.Z` обновляет этот журнал: все изменения,
  вошедшие в версию, получают её номер.
- История до 1.7.27 — в GitHub Releases; журнал ведём начиная с 1.7.27.
