# muzea (Android-клиент)

Мобильное приложение: новости, видео, контакты, профиль и чат (текст, вложения,
гифки). Клиент работает с двумя сервисами: `api-muzea.su` (makeup) и
`chat-muzea.su` (chat).

Ниже — характеристики кэшей и таймингов: **что и сколько живёт**.

## Кэши

| Что | Где хранится | Время жизни | Ограничения | Сброс |
|-----|--------------|-------------|-------------|-------|
| Медиа (гифки, картинки, превью) | Диск устройства (Glide, `filesDir`/cache) | До вытеснения по размеру (LRU, дефолт Glide ~250 МБ); переживает перезапуск | ~250 МБ (настраивается) | Очистка кэша в профиле |
| Списки гифок пикера («Мои», «Этот чат», поиск) | Файл `filesDir/gif_cache.json` (Gson) | «Известный» список живёт бессрочно; **сверка при открытии вкладки, если старше 30 мин** | ≤100 ключей, ≤60 элементов на список | Выход из аккаунта; живое дополнение при новых гифках (без сброса) |
| Сообщения переписки | Память процесса | Пока жив процесс (теряется при перезапуске) | ≤50 чатов | Выход из аккаунта |
| Список чатов | Память процесса | Пока жив процесс | ≤200 чатов | Выход из аккаунта |
| Список видео | Память процесса | Пока жив процесс | ≤200 видео | Выход из аккаунта |
| Личные чаты (по пользователю) | Память процесса | Пока жив процесс | ≤200 записей | Выход из аккаунта |
| Пароль + токены (`auth_token`, `chat_token`) | `EncryptedSharedPreferences` (Android Keystore) | До логаута/удаления аккаунта | — | Логаут / удаление аккаунта |
| Профиль/настройки (`username`, `email`, …) | Обычные SharedPreferences (`app_prefs`) | До логаута/удаления | — | Логаут / удаление аккаунта |
| Доступное обновление приложения | Память (StateFlow) | Пока жив процесс (и пока есть релиз новее) | — | При перезапуске проверяется заново |

## Тайминги (фоновые обновления)

| Что | Интервал | Условие |
|-----|----------|---------|
| Опрос новых сообщений в открытой переписке | 3 с | Пока переписка открыта (отменяется при закрытии) |
| Догрузка истории сообщений вверх | по скроллу (страница 50), не поллинг | — |
| Обновление списка чатов | 8 с | Пока экран чатов виден (RESUMED) |
| Предзагрузка переписок из списка чатов | 20 чатов за проход, пауза 250 мс | Фоном, пока виден список |
| Бейдж непрочитанных сообщений | 10 с | Пока приложение на переднем плане |
| Heartbeat «в сети» (presence) | 15 с | Пока приложение на переднем плане (сервер считает онлайн 45 с) |
| Presence в контактах | 20 с | Пока экран контактов открыт |
| Проверка обновления приложения | при старте + при открытии профиля | Без таймера |

## Гифки (кратко)

- Единственный провайдер — **Klipy**. **Поиск** идёт **напрямую с устройства**
  (ключ зашит в сборку, безопасный контент-фильтр) — так требует провайдер;
  наш сервер его не проксирует и медиа не хранит.
- **«Мои»/«Этот чат»** — с нашего API (метаданные отправленных гифок); медиа
  грузится по URL Klipy.
- В переписке гифка играет как беззвучное mp4 (Media3), с откатом на WebP/GIF.
- Каждая гифка хранит наш ключ; поиск/списки кэшируются на устройстве (см. таблицу).
- В пикере показывается брендинг «Powered by KLIPY» (требование провайдера).
