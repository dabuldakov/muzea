# AGENTS.md

## Git и релизы

- **Не коммитить, не создавать теги и не пушить** изменения без явной команды
  пользователя («коммить», «пуш», «релиз» и т.п.).
- По умолчанию изменения остаются локальными: сначала показываем результат,
  ждём подтверждения.
- Релиз (тег `v*`) создаётся только по отдельной команде.
- Секреты и keystore (`muzea.jks`, `keystore.properties`, пароли) в git не
  добавлять.
